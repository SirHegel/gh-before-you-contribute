# Support

For public usage questions, integration design, and examples, search or open a topic in
the answerable
[Q&A category](https://github.com/SirHegel/gh-before-you-contribute/discussions/categories/q-a).
An accepted answer remains available to the next person with the same question.

For reproducible bugs and feature requests, use the matching
[GitHub issue template](https://github.com/SirHegel/gh-before-you-contribute/issues/new/choose).
Report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/SirHegel/gh-before-you-contribute/security/advisories/new),
not in an issue or discussion.

For support that should not be posted publicly, email
[alvarezruizj289@gmail.com](mailto:alvarezruizj289@gmail.com).

For a reproducible question or bug, include the command version, operating system, exit
code, and a redacted copy of the output. Never include GitHub tokens, private repository
contents, source excerpts from private policy documents, or other secrets.
